Petunjuk singkat

Setiap tamu mendapatkan tautan dengan parameter ?to=. Link dapat dibagikan melalui WhatsApp. Data tamu hanya tersimpan di browser admin ini, bukan di GitHub atau server publik. Gunakan Ekspor CSV untuk cadangan data.

Keamanan: Halaman /admin/ bukan login privat. Siapa pun yang mengetahui alamatnya dapat membuka halaman admin kosong miliknya sendiri. Untuk akun admin dengan login dan database tersinkron, diperlukan layanan backend seperti Firebase atau Supabase.
